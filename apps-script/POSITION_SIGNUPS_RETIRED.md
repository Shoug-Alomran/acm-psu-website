# Legacy position signups — retired

Club membership and event-position applications now use the authenticated
Supabase portal. Public `positions.html` links to `/portal/opportunities.html`.
Legacy `Position Signups` and `Positions` tabs are historical reference data;
retain them without adding new registrations. `Position Applications` remains
a canonical Supabase snapshot.

This retirement does **not** apply to public team registrations for Jam and CTF.
Their `jam26` and `ctf30` tabs use the active Apps Script event deployment described
in [SETUP.md](SETUP.md). The current endpoint accepts no membership application,
position-signup, FAQ contact, or arbitrary-sheet action. Do not archive the active
event deployment when retiring obsolete deployments.
